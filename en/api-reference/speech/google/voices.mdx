Call Google TTS with `POST /v1/audio/speech`. Send a configured `model`, string `input`, and top-level `voice`. The gateway converts the request and processes the audio.

## Model catalog

A Google catalog snapshot checked on October 15, 2026 lists five HTTP TTS models, **70 distinct preset voice IDs**, and 230 model-voice associations. The official preset page lists 30 voices; the 3.8 series includes 40 more in this snapshot.

| Model | Voices in snapshot | List |
| --- | --- | --- |
| `gemini-3.8-flash-tts` | 70 | 30 shared voices + 40 new voices |
| `gemini-3.8-flash-lite-tts` | 70 | Same snapshot list as 3.8 Flash |
| `gemini-3.1-flash-tts-preview` | 30 | Shared voices only |
| `gemini-2.5-pro-preview-tts` | 30 | Shared voices only |
| `gemini-2.5-flash-preview-tts` | 30 | Present in snapshot; absent from current official support table |

Model availability depends on your Tikway account and the current model catalog. The `models/` prefix belongs to Google's catalog; use a configured Tikway ID or alias such as `google/gemini-3.8-flash-tts`.

<Note>
The request schema accepts a voice name or ID instead of restricting it to this snapshot. Gemini 3.8 can also use available voices from a Google project. Check model and account access before using an ID.
</Note>

## How to read the voice lists

- `voice` is an exact, case-sensitive name such as `Kore`, `Zephyr`, or `Arlo`.
- Voice character, pitch, accent, and suggested uses help you choose a voice. They are not parameters of this endpoint.
- The sample language in the snapshot is `en-US`; this does not mean synthesis is English-only. Language support varies by model.
- Click a voice ID to hear its provider sample.

## Standard request

```json
{
  "model": "google/gemini-3.8-flash-tts",
  "input": "Hello, welcome to speech synthesis.",
  "voice": "Kore",
  "instructions": "Read in a warm, clear style.",
  "response_format": "wav",
  "extra_body": { "language_code": "en-US" }
}
```

| Field | Gateway behavior |
| --- | --- |
| `model`、`input`、`voice` | Required. `input` must be a string of at most 4,096 characters. |
| `voice` | A name or ID string; `{ "id": "Kore" }` is also accepted. |
| `instructions` | On 3.8, used as style metadata; on 2.5/3.1, used in the older prompt text. |
| `speed` | Range 0.25–4, default 1. Google approximates this through style instructions, so exact speed is not guaranteed. |
| `response_format` | Google supports `wav` and `pcm`; default `wav`. |
| `stream_format` | `audio` returns audio bytes; `sse` returns gateway events. |
| `extra_body` | Google extensions. Fields may also appear at the body root; root values take precedence. |

Provider extensions include `language_code`, `speech_metadata`, `generation_config`, `multi_speaker_voice_config`, and text `contents`. Only the verified `temperature` option is shown under `generation_config`.

<Note>
The Google adapter receives the full synthesized result before wrapping it in `speech.audio.delta` and `speech.audio.done`. `stream_format=sse` does not imply low-latency upstream synthesis. WAV has a container header; PCM does not.
</Note>

## Gemini 3.8 and older previews

Gemini 3.8 treats the main text as words to read verbatim. Send style guidance through top-level `instructions` or `speech_metadata.style`. The 2.5/3.1 adapter uses the older prompt-text behavior, so instruction effects may differ.

Gemini 3.8 can use an existing `voice_...` or `voicekey_...` in your Google project. Send it as a `voice` string or `{ "id": "voice_..." }`. This endpoint uses existing voices; it does not create, clone, or list voices. Those IDs are not documented as supported on 2.5/3.1.

## Multiple speakers

The gateway supports up to two speakers. Configure preset voices in `extra_body.multi_speaker_voice_config`, then assign each turn with `extra_body.contents[].parts[].speech_metadata.speaker`.

```json
{
  "model": "google/gemini-3.8-flash-tts",
  "input": "A greeting between Joe and Jane.",
  "voice": "Kore",
  "response_format": "wav",
  "extra_body": {
    "multi_speaker_voice_config": {
      "speakerVoiceConfigs": [
        { "speaker": "Joe", "voiceConfig": { "prebuiltVoiceConfig": { "voiceName": "Puck" } } },
        { "speaker": "Jane", "voiceConfig": { "prebuiltVoiceConfig": { "voiceName": "Kore" } } }
      ]
    },
    "contents": [{ "role": "user", "parts": [
      { "text": "Hello, how are you today?", "speech_metadata": { "speaker": "Joe", "style": "cheerful and friendly" } },
      { "text": "I'm well, thanks for asking.", "speech_metadata": { "speaker": "Jane", "style": "calm and relaxed" } }
    ] }]
  }
}
```
