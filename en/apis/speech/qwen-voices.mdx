When calling `POST /v1/audio/speech`, send the selected `voice` at the request body root. Choose the model first, then select a voice supported by that model.

<Note>
Voice IDs are case sensitive. Keep version suffixes and spaces exactly as shown. Voices from different models are not interchangeable; for example, `longanhuan_v3.1` belongs to Qwen-Audio 3.1, not Qwen3-TTS.
</Note>

## Request examples

Use a string `input` and a top-level `voice`. You can pass a configured model ID or alias.

### Qwen3-TTS

```json
{
  "model": "qwen3-tts-flash",
  "input": "Hello, welcome to speech synthesis.",
  "voice": "Cherry",
  "response_format": "wav",
  "extra_body": { "language_type": "English" }
}
```

### Qwen-Audio 3.1

```json
{
  "model": "qwen-audio-3.1-tts-flash",
  "input": "Hello, welcome to speech synthesis.",
  "voice": "Emily_v3.1",
  "response_format": "wav"
}
```

`language_type` is a Qwen3-TTS extension. Put it in `extra_body`, or at the request body root. A root value wins if both are present. Do not send it to Qwen-Audio.
