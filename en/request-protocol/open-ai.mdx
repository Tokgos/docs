The OpenAI-compatible API uses `Authorization: Bearer <API Key>`. Set your SDK base URL to `https://api.tikway.ai/v1` and pass a Tikway model ID in the `model` field.

| API | Path | Best for |
| --- | --- | --- |
| Chat Completions | `POST /v1/chat/completions` | Chat messages, tool calls, and streaming with the `messages` array. |
| Responses | `POST /v1/responses` | Multi-turn, tool, and multimodal workflows built around `input` and response items. |
