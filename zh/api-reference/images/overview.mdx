图片 API 提供文生图、参考图生成和图像编辑能力。先选择模型，再按下表设置生成数量、参考图和输出规格；同名参数在不同模型下可能有不同含义。

<Note>
本页按 Tikway 当前接口定义整理。表中的数量均为**单次请求**的限制；“未开放”表示当前接口没有开放该字段，不代表上游模型没有这项能力。模型是否可用，以你的账号可调用模型列表为准。
</Note>

## 接口选型

| 使用场景 | 请求入口 | 必填内容 |
| --- | --- | --- |
| 根据文字生成图片 | `POST /v1/images/generations` | `model`、`prompt` |
| Nano Banana、Qwen、Seedream、MAI、Novel、Flux、Grok 参考图生成 | `POST /v1/images/generations` | `model`、`prompt`，以及对应格式的 `images` |
| GPT Image / DALL·E 2 图像编辑 | `POST /v1/images/edits` | `model`、`prompt`、`images` |
| Nano Banana 原生 Gemini 请求 | `POST /v1beta/models/{model}:generateContent` | 路径中的模型 ID、请求体中的 `contents` |
| Midjourney 生成、变体与局部重绘 | 生成接口提交任务，再查询任务结果 | 见 [Midjourney 上手与参数指南](/zh/api-reference/images/midjourney/guide) |

## 模型速查

先看数量范围，再展开对应模型查看完整参数。**输出数量与输入参考图数量分别计算。**

| 模型系列 | 输出数量 | 参考图上限 |
| --- | --- | --- |
| GPT Image / DALL·E | 1–10；DALL·E 3 仅 1 | GPT 编辑 16 张；DALL·E 2 编辑 1 张 |
| Nano Banana | 未开放 `n` | Gemini 3 系列 14 张；2.5 建议最多 3 张 |
| Qwen Image | 不接受 `n` | 3 张 |
| Seedream | 未开放 `n` | 5.0 Pro 为 10 张；4.5 为 14 张 |
| MAI Image | 每次 1 张 | 1 张 |
| Novel | 1–4 | 总计 16 项；普通源图仅 1 张 |
| Flux | 每次 1 张 | 4 张 |
| Grok | 1–4 | 5 张 |

Midjourney 使用异步任务和四宫格结果，见 [专门指南](/zh/api-reference/images/midjourney/guide)。

| 参数 | 说明 |
| --- | --- |
| `background` | `auto / opaque / transparent`。GPT Image；透明背景须配合 `png` 或 `webp`；GPT Image 2 透明背景为预览能力 |

| `output_compression` | 整数 `0–100`，默认 `100`。仅 GPT Image 的 JPEG / WebP 输出 |

| `mask` | `{ "image_url": "…" }` 或 `{ "file_id": "…" }`。编辑接口的局部重绘遮罩，两种来源二选一 |
| `style` | `vivid / natural`。仅 DALL·E 3 文生图 |
| `user` | string。终端用户标识，用于滥用监控 |

GPT 编辑的 `images` 使用对象数组，每项填写 `image_url` 或 `file_id` 之一；`image_url` 可以是完整 URL 或 Base64 data URL。DALL·E 3 没有编辑能力。

## 通用参数

| 参数 | 说明 |
| --- | --- |
| `model` | string。必填。填写可调用的模型 ID 或别名，不能只填写厂商名称 |
| `prompt` | string。必填且非空。描述主体、场景、构图、风格；编辑时写清要修改与保留的部分 |
| `images` | array。可选参考图；GPT 编辑接口必填。元素结构与数量随模型变化 |
| `n` | integer。仅在模型支持时填写；范围见上表，不支持时直接省略 |
| `size` | string。输出像素尺寸或宽高比；不同模型的写法见下一节 |
| `quality` | string。GPT Image 中控制质量，Nano Banana / Grok 中控制分辨率；不能跨模型照搬取值 |
| `response_format` | string。`url` 返回图片地址，`b64_json` 返回纯 Base64；默认 `url` |
| `output_format` | string。图片编码，如 PNG、JPEG、WebP；仅部分模型开放 |
| `seed` | integer / string。部分模型支持随机种子。类型与范围见模型说明，固定种子不保证结果完全一致 |

`response_format` 决定**如何交付图片**，`output_format` 决定**图片文件格式**。例如 `response_format="url"` 与 `output_format="png"` 可以一起使用，表示返回 PNG 图片的链接。

## 请求示例

除原生 Gemini 入口外，以下请求体均使用 `Content-Type: application/json` 与 `Authorization: Bearer YOUR_TIKWAY_API_KEY`。参考图 URL 为占位示例，使用时换成可访问的素材地址。

<Tabs>
<Tab title="GPT 文生图">

`POST /v1/images/generations`：生成 2 张横图。

```json
{
  "model": "gpt-image-1.5",
  "prompt": "白色陶瓷咖啡杯，浅灰背景，柔和自然光，产品摄影",
  "n": 2,
  "size": "1536x1024",
  "quality": "high",
  "output_format": "png",
  "response_format": "url"
}
```

</Tab>
<Tab title="GPT 图片编辑">

`POST /v1/images/edits`：传入源图并描述修改要求。

```json
{
  "model": "gpt-image-1.5",
  "prompt": "将杯子改为深蓝色，保留构图、光线和背景",
  "images": [{ "image_url": "https://example.com/cup.png" }],
  "n": 1,
  "size": "1024x1024",
  "response_format": "url"
}
```

</Tab>
<Tab title="Nano Banana 参考图">

`POST /v1/images/generations`：用 `size` 设比例，用 `quality` 选择 2K。

```json
{
  "model": "gemini-3.1-flash-image",
  "prompt": "保留参考图中的杯子外观，将它放在木质书桌上",
  "images": [{ "image_url": "https://example.com/cup.png" }],
  "size": "16:9",
  "quality": "medium",
  "response_format": "url"
}
```

## 常见参数组合问题

| 现象 / 请求写法 | 原因 | 调整方式 |
| --- | --- | --- |
| Qwen 请求带 `n=1` | 当前入口不接受 `n` | 删除 `n` |
| Nano Banana 传 `size="1024x1024"` | 当前公开字段使用比例枚举 | 改用 `1:1`，分辨率由 `quality` 控制 |
| Grok 增大 `size`，图片分辨率没有提高 | `size` 用于推导比例 | 用 `quality="hd"` 选择 2K |
| 透明背景配合 JPEG | JPEG 不支持透明通道 | GPT 选 PNG / WebP；Seedream 选 PNG |
| 参考图超限或返回字段错误 | 输入数量、格式与所选模型不匹配 | 先查数量表，再查该模型的 `images` 结构 |
| 所有模型复用同一组可选参数 | 支持字段和枚举各不相同 | 只发送该模型支持的参数 |
