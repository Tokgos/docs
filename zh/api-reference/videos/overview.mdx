视频 API 通过统一的 `POST /v1/videos` 创建任务，覆盖文生视频、图生视频、参考素材生成，以及部分模型的视频编辑和延长。选择模型后，再确定时长、分辨率和素材类型。

<Note>
本页按 Tikway 当前接口及网关支持范围整理。数量限制均指单次请求；同一模型的文生、参考、编辑和延长模式可能有不同限制。模型可用性以你的账号为准。
</Note>

## 调用方式与生成数量

| 步骤 | 接口 / 字段 | 说明 |
| --- | --- | --- |
| 创建任务 | `POST /v1/videos` | 提交 JSON 请求，保存返回的 `id` 和 `polling_url` |
| 查询任务 | `GET /v1/videos/{id}` | 查询进度与最终结果，也可请求返回的 `polling_url` |
| 获取视频 | `data.video_url.url` | 仅在 `status="completed"` 时读取 |
| 接收通知 | 创建时传 `callback_url` | HTTPS 回调地址，由 Tikway 通知任务状态变化 |

**当前统一接口没有开放批量数量参数 `n`。** 一次创建请求对应一个任务，完成后返回结果对象；需要多个视频时，分别创建任务并保存各自的 ID。参考素材数量不是生成视频数量。

## 模型速查

这里只列生成规格，参考素材数量和扩展参数集中在下方的模型详情中。

| 模型系列 | 生成时长 | 分辨率 |
| --- | --- | --- |
| Seedance | 2.5：4–30 秒；2.0 / Mini：4–15 秒 | 480p–4K，依版本而定 |
| Wan | 3.0：2–30 秒；2.7 / 2.6：生成 2–15 秒 | 480p–1080p，依版本而定 |
| HappyHorse | 3–15 秒 | 480p / 720p / 1080p |
| MiniMax H3 | 4–15 秒 | 768p / 2K |
| Veo | 4、6、8 秒 | 720p / 1080p |
| Grok | Fast：6–30 秒；1.5 / 基础版：1–15 秒 | 480p–1080p，依版本而定 |
| FLUX 3 Video | 5–20 秒或 `auto` | HD / FHD |

编辑、参考和延长任务可能使用不同的时长限制，详见对应模型。

## 素材字段怎么选


| 参数 | 说明 |
| --- | --- |
| `frame_images` | 指定开始或结束画面。每项填 `type="first_frame"` 或 `"last_frame"`，以及 `image_url` |
| `reference_image` | 主体、风格等图片参考。`input_references` 中填 `role` 与 `image_url` |
| `reference_video` | 视频参考。填 `role` 与 `video_url`，仅对应模型支持时使用 |
| `reference_audio` | 音频参考。支持音频素材的模型填 `audio_url`；Grok 1.5 用 `reference_voice` |
| `source_video` | 待编辑的源视频。填 `video_url`；用于支持编辑的模型 |
| `first_clip` | 要延长或续写的视频。填 `video_url`；用于支持延长的模型 |
| `keyframe` | 指定时间点的画面。Grok 1.5 系列 / FLUX 使用 `image_url`、`seconds` |
| `driving_audio` | 驱动音频。Wan 的相应模式使用 `audio_url` |
| `file` / `link` | 文件或网页参考。Wan 3.0 使用 `file_url` / `link_url`，两者互斥 |

每个参考项只放一种素材 URL。可选的 `type` 若填写，必须与 URL 字段一致，例如 `type="image_url"` 配合 `image_url`。Grok 预设音色是例外：只填 `role="reference_audio"` 与 `reference_voice`，不要附加 `audio_url` 或 `type`。

## 请求参数详解

| 参数 | 说明 |
| --- | --- |
| `model` | string。必填。模型 ID；Wan 3.0 还接受 `wan3.0-video` 别名 |
| `prompt` | string。生成、编辑或续写指令。文生视频应填写；MiniMax、Veo、Grok 明确要求必填 |
| `duration` | integer，部分模型支持 string。单位为秒；MiniMax 必填，其他模型的范围和特殊值见规格表 |
| `resolution` | string。输出分辨率；MiniMax 必填。注意 `4K`、`2K` 与 `1080p` 是不同枚举 |
| `aspect_ratio` | string。输出宽高比；图生视频时部分模式会跟随输入素材 |
| `frame_images` | array。首尾帧数组；同一类型最多 1 张，且必须符合所选模型的能力 |
| `input_references` | array。图片、视频、音频或关键帧参考；类型、角色与数量均有模型限制 |
| `generate_audio` | boolean。Seedance、Wan、FLUX 支持；没有开关的模型应省略该字段 |
| `seed` | integer。Seedance、Wan、HappyHorse 支持 `-1–2147483647`；固定种子不保证完全相同的结果 |
| `negative_prompt` | string。Wan 2.6 / 2.7 可用；Wan 3.0 不支持此顶层字段 |
| `size` | string。仅 Wan 2.6 支持精确像素尺寸，格式 `WIDTHxHEIGHT` 或 `WIDTH*HEIGHT` |
| `callback_url` | string。HTTPS URL；由 Tikway 回调，不直接传给模型上游 |
| `extra_body` | object。所选模型的扩展参数，见下表；不是任意字段的通用透传容器 |

## 参数组合限制

| 场景 | 约束 | 正确用法 |
| --- | --- | --- |
| Seedance / MiniMax 全模态参考 | 不能与首尾帧模式混用 | 在 `frame_images` 与 `input_references` 中选择一种模式 |
| Wan 3.0 参考素材 | 不能与首尾帧混用；文件与链接互斥 | 最多 10 图 + 5 视频 + 5 音频，再选择 1 个文件或链接 |
| Seedance 2.0 Mini | 不支持全模态参考、编辑或延长 | 使用文字或首尾帧生成 |
| HappyHorse 编辑 | 仅 1.0 支持；忽略 `duration` | 提供源视频，可加最多 5 张参考图，分辨率用 720p / 1080p |
| Veo 1080p / 普通参考图 | 时长必须为 8 秒 | 显式传 `duration=8`；Lite 不传普通参考图 |
| Grok 视频延长 | 仅基础版，且只能有 1 个视频素材 | 使用 `source_video` 或 `first_clip`，时长 1–10 秒 |
| Grok 预设音色 | 仅 1.5，最多 3 个 | 填 `reference_voice`，不上传音频 URL |
| Grok 定时关键帧 | 最多 4 张，`seconds` 大于 0 | 为每张图填写 `role="keyframe"` 与目标秒数 |
| FLUX 普通 / 定时关键帧 | 两种形式不能混用，总数 1–10 张 | 整组统一用 `reference_image` 或 `keyframe` |
| FLUX 视频续写 | 必须且只能提供 1 个源视频 | 用 `source_video` 或 `first_clip`，不附带额外参考素材 |

### 查询与结果处理

创建成功后，用返回的任务 ID 查询：

```bash
curl https://api.tikway.ai/v1/videos/YOUR_TASK_ID \
  -H "Authorization: Bearer YOUR_TIKWAY_API_KEY"
```

| `status` | 含义 | 接下来做什么 |
| --- | --- | --- |
| `pending` / `queue` | 等待处理 / 排队 | 稍后继续查询 |
| `in_progress` | 正在生成或处理资源 | 继续等待，不读取最终 `data` |
| `completed` | 视频与资源处理完成 | 读取 `data.video_url.url` |
| `failed` | 任务失败 | 查看 `error`，修正参数或素材后再提交 |
| `cancelled` / `expired` | 已取消 / 已过期 | 停止轮询，需要时重新创建任务 |

最终 `data` 是对象，不是数组；未完成时省略整个 `data` 字段。不要把任务创建成功当成视频已经生成完成，也不要因为暂时没有 `data` 就重复提交同一个生成请求。
