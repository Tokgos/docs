调用 `POST /v1/audio/speech` 时，将下表中的 `voice` 值放在请求体顶层。先选择模型，再选择该模型支持的音色。

> **说明**：`voice` 区分大小写，版本后缀和名称中的空格也必须保留。不同模型的音色不能混用，例如 `longanhuan_v3.1` 属于 Qwen-Audio 3.1，不能用于 Qwen3-TTS。

## 模型速查

本页完整列出四个非实时模型的 **130 个系统音色条目**。模型是否可调用，以平台模型广场为准；Qwen-Audio 3.0 的基础音色下载入口见文末。

| 模型 | 系统音色数 | `voice` 示例 |
| --- | --- | --- |
| `qwen3-tts-flash` | 48 | `Cherry` |
| `qwen-audio-3.1-tts-flash` | 68 | `longanhuan_v3.1` |
| `qwen-audio-3.0-tts-plus` | 2 | `longanlingxin` |
| `qwen-audio-3.0-tts-flash` | 12 | `longanhuan_v3.6` |

## 请求示例

使用平台统一的 `input` 字符串和顶层 `voice`。`model` 可以填写平台已配置的模型 ID 或别名。

```json
{
  "model": "qwen3-tts-flash",
  "input": "你好，欢迎使用语音合成。",
  "voice": "Cherry",
  "response_format": "wav",
  "extra_body": {
    "language_type": "Chinese"
  }
}
```

```json
{
  "model": "qwen-audio-3.1-tts-flash",
  "input": "你好，欢迎使用语音合成。",
  "voice": "longanhuan_v3.1",
  "response_format": "wav"
}
```

`language_type` 是 Qwen3-TTS 的扩展参数，建议放入 `extra_body`；也兼容直接放在请求体顶层，顶层同名字段优先。不要把它套用到 Qwen-Audio 请求中。

## 基础音色与试听

Qwen-Audio 3.0 Plus 和 Flash 在系统音色之外，还分别提供 500 余个基础音色。需要更多选择时，可下载官方完整清单；这些条目不计入上方系统音色数量。

- [Qwen-Audio 3.0 Plus 基础音色清单（Excel）](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20260723/ydwqqz/qwen-audio-3.0-tts-plus%E5%9F%BA%E7%A1%80%E9%9F%B3%E8%89%B2.xlsx)
- [Qwen-Audio 3.0 Flash 基础音色清单（Excel）](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20260723/thosjr/qwen-audio-3.0-tts-flash%E5%9F%BA%E7%A1%80%E9%9F%B3%E8%89%B2.xlsx)

基础音色 ID 的前缀与模型绑定：`qwen-audio-3.0-tts-plus-...` 和 `qwen-audio-3.0-tts-flash-...` 不能互换。请复制清单中的完整 ID，不要仅传末尾后缀。

各模型小节中的官方链接提供在线试听。使用前先核对模型、音色 ID 和文本语言，再试听确认是否符合场景。
