OpenAI 兼容协议使用 `Authorization: Bearer <API Key>` 鉴权。SDK 的 Base URL 为 `https://api.tikway.ai/v1`。请求体中的 `model` 使用 Tikway 模型标识。

| 接口 | 路径 | 适用场景 |
| --- | --- | --- |
| Chat Completions | `POST /v1/chat/completions` | 使用 `messages` 构建常见聊天、工具调用和流式输出。 |
| Responses | `POST /v1/responses` | 使用 `input` 与响应 item 构建多轮、工具和多模态工作流。 |
