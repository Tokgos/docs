## 已弃用参数

以下官方字段仍可能出现在旧项目中，但新接入不建议使用：

```json
{
  "max_tokens": 800,
  "functions": [],
  "function_call": "auto",
  "prompt_cache_retention": "24h",
  "user": "user_123456"
}
```

请分别替换为 `max_completion_tokens`、`tools`、`tool_choice`、`prompt_cache_options` 与 `safety_identifier`。
