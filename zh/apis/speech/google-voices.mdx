通过 `POST /v1/audio/speech` 调用 Google TTS。你只需填写平台的 `model`、字符串 `input` 和顶层 `voice`；网关负责原生请求转换和音频处理。

## 目录分析

本页依据 2026-10-15 核对的 Google 模型目录快照及官方文档整理。目录同时包含文本、图像、Live 和 TTS 等模型；本文范围为 HTTP TTS，共有五个模型、**70 个不同的预置音色 ID**及 230 条模型与音色关联。

官方页面展示 30 个精选预置音色，目录中的 3.8 系列还列出 40 个新增音色。下表保留两组清单及对应的模型范围。

| 模型 | 快照音色数 | 使用清单 |
| --- | --- | --- |
| `gemini-3.8-flash-tts` | 70 | 30 个通用音色 + 40 个新增音色 |
| `gemini-3.8-flash-lite-tts` | 70 | 与 3.8 Flash 的快照清单完全相同 |
| `gemini-3.1-flash-tts-preview` | 30 | 仅下方通用音色 |
| `gemini-2.5-pro-preview-tts` | 30 | 仅下方通用音色 |

<Note>
  清单完整覆盖上述目录快照。3.8 还支持 Google 动态语音库及项目自定义音色，因此 Body Schema 保持 `voice` 为名称或 ID，不锁定为 30 或 70 个枚举值。选择时需核对模型和账号权限。
</Note>

## 如何读音色信息

- `voice` 是调用时传入的准确名称，区分大小写，如 `Kore`、`Zephyr`、`Arlo`。
- 声线、音高、口音和用途是音色元数据，用于选择音色；它们不是可直接传给本接口的调节参数。
- 快照中的试听语言统一标为 `en-US`，不代表只能合成英语。语言覆盖范围取决于模型；官方说明 3.8 Flash 支持 130 多种语言，Flash-Lite 支持 100 多种。
- 两代模型对同一音色的用途标签可能不同，不能把某个推荐场景解释为功能限制。下表声线和音高按快照整理，点击 ID 可打开官方试听音频。

## 标准请求

```json
{
  "model": "google/gemini-3.8-flash-tts",
  "input": "你好，欢迎使用语音合成。",
  "voice": "Kore",
  "instructions": "用温和、清晰的语气朗读。",
  "response_format": "wav",
  "extra_body": {
    "language_code": "cmn-CN"
  }
}
```

| 字段 | 当前平台行为 |
| --- | --- |
| `model`、`input`、`voice` | 必填；`input` 为字符串，网关上限 4096 字符 |
| `voice` | 名称或 ID 字符串，也接受 `{ "id": "Kore" }` |
| `instructions` | 3.8 作为风格元数据；2.5/3.1 使用旧版提示文本 |
| `speed` | 标准范围 0.25–4，默认 1；Google 通过风格提示近似控制，不保证精确倍速 |
| `response_format` | 当前 Google 适配仅支持 `wav` / `pcm`，默认 `wav` |
| `stream_format` | `audio` 返回音频字节；`sse` 返回平台统一事件 |
| `extra_body` | Google 扩展；同名字段也可直接放在顶层，顶层优先，仅展开一层 |

扩展包括 `language_code`、`speech_metadata`、`generation_config`、`multi_speaker_voice_config` 和文本 `contents`。其中 `generation_config` 本次只展示已核对的 `temperature` 配置，不照搬整套 Google 原生参数。

<Note>
  当前 Google 适配先接收完整合成结果，再封装成 `speech.audio.delta` / `speech.audio.done`。`stream_format=sse` 不能理解为上游已经启用低延迟流式合成。WAV 自带容器头，PCM 没有文件头；采样率沿用实际音频信息。
</Note>

## 3.8 与旧预览版的差异

Gemini 3.8 把正文作为逐字朗读内容，风格指令应通过顶层 `instructions` 或扩展的 `speech_metadata.style` 传入。2.5/3.1 的网关适配仍使用旧版提示文本，不能承诺与 3.8 完全一致的指令效果。

3.8 可以引用当前 Google 项目已有的 `voice_...` 或 `voicekey_...`，直接传入 `voice` 字符串或 `{ "id": "voice_..." }`。本接口只消费已有音色，不提供创建、复刻或语音目录查询接口；也不把这些音色 ID 作为 2.5/3.1 的可用参数。

## 多说话人

当前网关支持最多两名说话人，使用 `extra_body.multi_speaker_voice_config` 配置预置音色，并通过 `extra_body.contents[].parts[].speech_metadata.speaker` 对应每个轮次。

```json
{
  "model": "google/gemini-3.8-flash-tts",
  "input": "Joe 与 Jane 的问候对话。",
  "voice": "Kore",
  "response_format": "wav",
  "extra_body": {
    "multi_speaker_voice_config": {
      "speakerVoiceConfigs": [
        {
          "speaker": "Joe",
          "voiceConfig": {
            "prebuiltVoiceConfig": {
              "voiceName": "Puck"
            }
          }
        },
        {
          "speaker": "Jane",
          "voiceConfig": {
            "prebuiltVoiceConfig": {
              "voiceName": "Kore"
            }
          }
        }
      ]
    },
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，今天过得怎么样？",
            "speech_metadata": {
              "speaker": "Joe",
              "style": "cheerful and friendly"
            }
          },
          {
            "text": "很好，谢谢你的关心。",
            "speech_metadata": {
              "speaker": "Jane",
              "style": "calm and relaxed"
            }
          }
        ]
      }
    ]
  }
}
```
